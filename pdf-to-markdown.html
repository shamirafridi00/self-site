PDF to Markdown, with tables and images intact

Turn reports, statements and papers into tidy Markdown. Text becomes headings, paragraphs and lists, tables become real Markdown tables, and every image is saved next to the file.

How it works

How to convert a PDF to Markdown

  1. Choose your PDF

    Drop it in or press Choose PDF. Password-protected files are supported.

  2. Pick the pages

    Convert the whole file or just a range, such as the transaction pages of a statement.

  3. Choose how to handle images

    Keep embedded images, add a snapshot of each page, or export text only.

  4. Copy or download

    Copy the Markdown straight into a chat, or download it as .md (or a ZIP with an images folder).

Good to know

Why Markdown is the best way to give a PDF to AI

AI assistants read text far more reliably than pictures of text. Markdown gives them exact numbers, dates and names, and keeps the structure: a heading stays a heading and a table stays a table. It’s also tiny, so long documents fit within upload and context limits.

For a bank statement, convert the transaction pages, press Copy Markdown, paste it into your chat and ask, for example, “list every cheque with its number, payee, date and amount”.

FAQ

Questions about PDF to Markdown

Does it work on scanned PDFs?

Scanned pages are pictures with no text layer. Shelf keeps them as page images in the Markdown so nothing is lost, but it doesn’t run OCR. Most AI chat tools can read those images directly.

How accurate are the tables?

Tables are rebuilt from where text sits on the page, which works well for statements, invoices and reports with clear columns. Cells that span several columns, or tables without gaps between columns, may need a quick tidy-up.

Can I paste the result into ChatGPT or Gemini?

Yes. Press Copy Markdown and paste it into the chat. If the document has important images, upload the ZIP’s images too.

What’s inside the download?

A single .md file when there are no images. Otherwise you get a ZIP with the .md file and an images folder it links to.

Can I convert password-protected PDFs?

Yes, if you know the password. Shelf asks for it and uses it only on your device.
